# Career Compass AI

Crie uma plataforma SaaS completa de inteligência artificial para otimização de currículos e candidaturas a vagas de emprego.

A referência de conceito e experiência é:
https://cvporvaga.com.br/

NÃO copie o design, textos, marca ou componentes exatamente. Use apenas como inspiração para entender o tipo de produto.

Quero uma identidade visual própria, moderna, premium e tecnológica.

CONCEITO DO PRODUTO

A plataforma deve ajudar uma pessoa a descobrir o quão compatível seu currículo está com uma vaga específica e, posteriormente, criar automaticamente uma versão otimizada do currículo para aquela vaga.

O fluxo principal será:

CURRÍCULO → VAGA → ANÁLISE IA → SCORE → MELHORIAS → CURRÍCULO OTIMIZADO → ESCOLHA DO MODELO → PDF

A ideia é que o usuário consiga fazer todo esse processo em poucos minutos.
